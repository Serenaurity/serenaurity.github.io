# Naphat Jakkraphatcharakul portfolio

Static HTML, CSS and JavaScript portfolio. No build step.

## Preview

Serve this directory over HTTP (for example `python -m http.server 8787`) and open http://localhost:8787.

## GitHub Pages

Repository: Serenaurity/serenaurity.github.io. Publish branch `main`, folder `/(root)` in Settings → Pages. `.nojekyll` disables Jekyll processing.

Publish only: index.html, style.css, script.js, repo-snapshot.js, .nojekyll, .gitignore, LICENSE, README.md, SOURCES.md and referenced assets. The allowlist in .gitignore excludes original Pic folders, previews, local notes and unused mockups.

## Images

Owner-supplied profile: `assets/profile.jpg`. Five project screenshots/figures live in `assets/project-images/`; their full-size links and captions are in index.html. Originals are preserved locally. Previous SVG mockups are retained locally but excluded from publication.
